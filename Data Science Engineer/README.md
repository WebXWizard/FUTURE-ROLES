# Data Science Engineer Revision

This folder is a structured Data Science Engineer learning path for analytics, statistics, Python, SQL, data engineering basics, machine learning, deep learning, cloud analytics, deployment, projects, and interview preparation.

Use it like this:

1. Start with `00-Data-Science-Engineer-Plan`.
2. Read each folder's `Study.md`.
3. Practice with datasets and notebooks.
4. Revise `Interview-questions.md`.
5. Build projects in `11-Data-Science-Projects`.
6. Use `14-Rapid-Revision` before interviews.

Daily routine:

```txt
45 min statistics or ML concepts
60 min Python, SQL, or notebook practice
45 min project work
30 min interview questions
15 min business explanation
```

Data Science Engineer answer formula:

```txt
Business problem -> Data -> EDA -> Features -> Model -> Evaluation -> Deployment -> Recommendation
```
