# MLOps Study Plan

MLOps Engineers make machine learning systems reliable, repeatable, deployable, and observable.

Focus on:

- ML lifecycle
- Python, Linux, Git
- Docker and containers
- Cloud infrastructure
- Data pipelines
- Experiment tracking
- Model registry
- Serving and inference
- CI/CD for ML
- Monitoring and drift detection
- Kubernetes and governance

Suggested order:

1. ML fundamentals for MLOps
2. Python, Linux, and Git
3. Docker and cloud
4. Data pipelines
5. Experiment tracking
6. Model serving
7. CI/CD for ML
8. Monitoring and drift
9. Kubernetes and governance
10. Projects and mock interviews
