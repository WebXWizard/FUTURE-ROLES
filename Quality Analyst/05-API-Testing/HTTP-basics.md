# HTTP Basics

Common HTTP methods:

- `GET`: read data
- `POST`: create data
- `PUT`: replace data
- `PATCH`: partially update data
- `DELETE`: remove data

Common status codes:

- `200`: OK
- `201`: Created
- `204`: No content
- `400`: Bad request
- `401`: Unauthorized
- `403`: Forbidden
- `404`: Not found
- `409`: Conflict
- `500`: Server error

API request parts:

- URL
- Method
- Headers
- Query parameters
- Path parameters
- Body
- Auth token
