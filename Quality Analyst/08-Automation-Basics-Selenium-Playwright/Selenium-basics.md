# Selenium Basics

Selenium is used to automate browser interactions.

Core ideas:

- WebDriver
- Browser driver
- Locators
- Actions
- Waits
- Assertions
- Test runner

Common locators:

- ID
- Name
- CSS selector
- XPath
- Link text

Good Selenium habits:

- Prefer stable locators.
- Use explicit waits.
- Keep tests independent.
- Avoid hard sleeps.
- Use Page Object Model for maintainability.
