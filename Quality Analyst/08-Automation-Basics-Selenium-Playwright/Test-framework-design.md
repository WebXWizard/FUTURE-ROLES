# Test Framework Design

A test framework organizes automation so tests stay maintainable.

Common parts:

- Test runner
- Page objects
- Test data
- Utilities
- Assertions
- Reports
- Config files
- Screenshots or traces
- CI integration

Good framework qualities:

- Easy to run
- Easy to debug
- Reusable methods
- Clear naming
- Stable locators
- Independent tests
- Meaningful reports

Mini design:

```txt
tests/
pages/
data/
utils/
reports/
```
