# Automation Strategy

Automate tests that are:

- Repeated often
- Stable
- Important for business
- Time-consuming manually
- Needed for regression
- Clear in expected result

Avoid automating tests that are:

- One-time checks
- Highly unstable
- Mostly visual judgment
- Unclear in requirements
- Too costly compared to value

Automation pyramid:

- Unit tests: many and fast
- API or integration tests: medium amount
- UI tests: fewer and focused on key journeys

QA interview line:

```txt
Automation does not replace manual testing. It supports regression speed and consistency.
```
