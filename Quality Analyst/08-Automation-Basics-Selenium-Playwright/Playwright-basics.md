# Playwright Basics

Playwright is a browser automation tool for reliable end-to-end testing.

Core ideas:

- Browser
- Page
- Locator
- Auto-waiting
- Assertions
- Test fixtures
- Tracing
- Screenshots and videos

Example checks:

```txt
Open page -> Fill login form -> Submit -> Assert dashboard is visible
```

Good Playwright habits:

- Use role-based locators when possible.
- Keep assertions close to user-visible behavior.
- Use traces for debugging failed tests.
- Keep tests small and readable.
