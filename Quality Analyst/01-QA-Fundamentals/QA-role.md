# QA Role

A Quality Analyst checks whether software is reliable, usable, secure, understandable, and aligned with business needs.

Core responsibilities:

- Understand requirements and acceptance criteria.
- Identify test scenarios and test data.
- Execute manual and automated tests.
- Report defects clearly.
- Retest fixes and perform regression testing.
- Communicate quality status to the team.
- Support release decisions with evidence.

QA mindset:

- Think like a user.
- Think like a risk analyst.
- Think like a system observer.
- Ask what can fail, who is affected, and how serious the impact is.

Common deliverables:

- Test plan
- Test scenarios
- Test cases
- Test data
- Defect reports
- RTM
- Test summary report
