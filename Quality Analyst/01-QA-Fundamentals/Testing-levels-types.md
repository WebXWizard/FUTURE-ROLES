# Testing Levels And Types

## Testing Levels

- Unit testing: tests small code units.
- Integration testing: tests communication between modules.
- System testing: tests the complete application.
- Acceptance testing: validates business expectations.

## Common Testing Types

- Functional testing
- Non-functional testing
- Smoke testing
- Sanity testing
- Regression testing
- Retesting
- Exploratory testing
- Usability testing
- Compatibility testing
- API testing
- Database testing
- Performance testing
- Security testing
- Accessibility testing

Interview tip:

- Explain level as where testing happens, and type as what quality aspect is being tested.
