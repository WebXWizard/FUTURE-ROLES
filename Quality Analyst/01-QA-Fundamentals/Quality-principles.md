# Quality Principles

Important testing principles:

- Testing shows the presence of defects, not their complete absence.
- Exhaustive testing is impossible.
- Early testing saves cost.
- Defects often cluster in risky or complex areas.
- Repeating the same tests without improvement loses value.
- Testing depends on context.
- A bug-free product can still fail if it does not meet user needs.

Quality is not only defect count.

Quality also includes:

- Correctness
- Usability
- Performance
- Security
- Accessibility
- Reliability
- Maintainability
- Compatibility

Practical habit:

- For every feature, ask: correct, clear, fast, safe, usable, and stable?
