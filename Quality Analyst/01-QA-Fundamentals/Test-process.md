# Test Process

Basic test process:

1. Understand requirements.
2. Identify risks.
3. Create test scenarios.
4. Design test cases and test data.
5. Execute tests.
6. Log defects.
7. Retest fixes.
8. Run regression tests.
9. Report test status.
10. Close testing with summary and lessons learned.

Good QA process includes:

- Clear entry criteria
- Clear exit criteria
- Traceability
- Evidence
- Defect tracking
- Communication
