# 12 Week QA Plan

## Week 1: QA Fundamentals

- Learn QA, QC, testing, verification, and validation.
- Study testing levels and testing types.
- Practice explaining the QA role in simple language.

## Week 2: SDLC, STLC, And Agile

- Learn waterfall, V-model, iterative, and Agile models.
- Study STLC phases from requirement analysis to closure.
- Learn user stories, acceptance criteria, sprint ceremonies, and Definition of Done.

## Week 3: Test Documentation

- Write test scenarios and test cases.
- Create checklists and test data.
- Build a simple RTM for one feature.

## Week 4: Manual Testing Techniques

- Practice boundary value analysis, equivalence partitioning, decision table, and state transition testing.
- Test login, registration, search, cart, checkout, and profile flows.

## Week 5: API Testing

- Learn HTTP methods, status codes, headers, body, query params, and auth.
- Build Postman collections.
- Write positive, negative, schema, and data validation tests.

## Week 6: Database And SQL Testing

- Practice `SELECT`, `WHERE`, `JOIN`, `GROUP BY`, and aggregate queries.
- Validate UI data against database data.
- Learn data integrity, duplicate checks, and backend validation.

## Week 7: Web And Mobile Testing

- Practice browser, responsive, form, accessibility, and compatibility testing.
- Learn mobile-specific checks for install, permissions, network, orientation, and interruption.

## Week 8: Defect Management

- Write clear bug reports.
- Learn defect lifecycle and severity vs priority.
- Practice Jira workflow and daily QA status updates.

## Week 9: Automation Basics

- Learn when to automate and when not to automate.
- Practice Selenium or Playwright locators, waits, assertions, and page objects.

## Week 10: Performance, Security, Accessibility

- Learn load, stress, spike, and endurance testing basics.
- Study common security and accessibility checks.
- Practice using Lighthouse, DevTools, and basic security test cases.

## Week 11: CI/CD And QA Projects

- Learn Git basics, CI smoke suites, build validation, release validation, and test environments.
- Complete two portfolio projects.

## Week 12: Interview Revision

- Revise top QA questions.
- Practice project explanation.
- Prepare resume points and mock interview answers.
