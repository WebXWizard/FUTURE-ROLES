# Quality Analyst Study Plan

Quality Analysts protect product quality by checking whether software meets requirements, user expectations, and business risk tolerance.

Focus areas:

- Understand QA roles, quality principles, and test levels.
- Learn SDLC, STLC, Agile, Scrum, and requirement analysis.
- Write test plans, test scenarios, test cases, checklists, and RTM.
- Practice manual testing techniques for web, mobile, API, and database flows.
- Learn defect management, Jira workflow, QA metrics, and reporting.
- Build automation awareness with Selenium, Playwright, and framework basics.
- Prepare projects, interview answers, and resume points.

Suggested order:

1. QA fundamentals
2. SDLC, STLC, and Agile
3. Test planning and documentation
4. Manual testing techniques
5. API testing
6. Web and mobile testing
7. Database and SQL testing
8. Automation basics
9. Performance, security, and accessibility basics
10. Defect management and QA reporting
11. CI/CD and DevOps QA
12. Projects and mock interviews
