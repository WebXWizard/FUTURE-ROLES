# Resources

Use these resource types while studying:

- ISTQB Foundation syllabus topics for testing fundamentals.
- Atlassian Agile and Jira guides for Agile QA workflow.
- Postman Learning Center for API testing.
- Playwright and Selenium official documentation for automation basics.
- W3C accessibility guidance for accessibility checks.
- OWASP Web Security Testing Guide for security testing awareness.
- SQL practice sites for database validation.

Practice resources:

- Test a demo e-commerce site.
- Test a demo banking or form-based application.
- Create Postman collections for public APIs.
- Write bug reports from real defects found during practice.
