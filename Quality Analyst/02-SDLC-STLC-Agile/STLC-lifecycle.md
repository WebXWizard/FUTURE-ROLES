# STLC Lifecycle

STLC means Software Testing Life Cycle.

Common phases:

1. Requirement analysis
2. Test planning
3. Test case design
4. Test environment setup
5. Test execution
6. Defect reporting
7. Retesting and regression
8. Test closure

Important outputs:

- Requirement questions
- Test plan
- Test scenarios
- Test cases
- Test data
- Defect reports
- Test execution report
- Test closure report

Exit criteria examples:

- Critical test cases passed.
- No open blocker defects.
- High priority defects resolved or accepted.
- Test summary shared with stakeholders.
