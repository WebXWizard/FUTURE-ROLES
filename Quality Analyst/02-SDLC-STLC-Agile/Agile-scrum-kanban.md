# Agile, Scrum, And Kanban

Agile is an iterative way of building software with fast feedback.

Scrum terms:

- Sprint
- Product backlog
- Sprint backlog
- User story
- Acceptance criteria
- Daily standup
- Sprint planning
- Sprint review
- Retrospective

Kanban terms:

- Board
- Work in progress
- Flow
- Cycle time
- Continuous delivery

QA in Agile:

- Review stories before sprint commitment.
- Clarify acceptance criteria.
- Prepare tests early.
- Test incrementally.
- Report risks daily.
- Support release readiness.
