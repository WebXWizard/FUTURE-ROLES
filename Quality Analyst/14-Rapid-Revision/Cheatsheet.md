# Cheatsheet

## QA Basics

- QA prevents defects through process and quality focus.
- QC detects defects in the product.
- Testing checks whether software behaves as expected.
- Verification asks: are we building it right?
- Validation asks: are we building the right thing?

## Testing Types

- Smoke: build stability check.
- Sanity: focused check after small change.
- Regression: existing functionality after changes.
- Retesting: specific defect fix.
- UAT: business acceptance.

## Defects

- Severity: impact.
- Priority: urgency.
- Good bug: clear, reproducible, evidence-based.

## API

- `GET`: read
- `POST`: create
- `PUT`: replace
- `PATCH`: partial update
- `DELETE`: remove
