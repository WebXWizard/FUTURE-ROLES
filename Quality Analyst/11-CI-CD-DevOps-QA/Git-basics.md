# Git Basics

QA may not write production code every day, but Git knowledge helps with builds, branches, and automation.

Useful terms:

- Repository
- Branch
- Commit
- Pull request
- Merge
- Tag
- Release branch

Common commands:

```bash
git clone <repo-url>
git branch
git checkout <branch>
git pull
git status
git log --oneline
```

QA uses Git to:

- Understand what changed.
- Pick correct build or branch.
- Review release notes.
- Run automation projects.
