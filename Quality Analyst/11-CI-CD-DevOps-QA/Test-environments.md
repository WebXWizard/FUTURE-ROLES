# Test Environments

Common environments:

- Dev
- QA
- Staging
- UAT
- Production

Environment checks:

- Correct version deployed
- Correct database connected
- Test data available
- Feature flags configured
- External services available
- Logs accessible
- Credentials working

Common environment issues:

- Wrong build deployed
- Cache not cleared
- Test data missing
- API endpoint incorrect
- Third-party service unavailable
- Permissions changed

QA habit:

- Confirm environment before reporting a functional defect.
