# Build And Release Validation

Build validation checks whether a new build is testable.

Build validation checks:

- Correct build version
- Application opens
- Login works
- Main flows accessible
- Critical APIs responding
- No blocker environment issue

Release validation checks:

- Release notes match tested scope.
- Critical regression passed.
- High severity defects resolved or accepted.
- Rollback plan exists.
- Stakeholders know remaining risks.

QA sign-off should include:

- Tested scope
- Test result
- Open defects
- Risks
- Recommendation
