# Test Plan

A test plan describes what will be tested, how it will be tested, who will test it, and when testing is complete.

Common sections:

- Scope
- Objective
- In-scope features
- Out-of-scope features
- Test approach
- Test environment
- Test data
- Roles and responsibilities
- Entry criteria
- Exit criteria
- Risks
- Deliverables

Good test plan qualities:

- Clear enough for the team to follow.
- Practical enough to execute.
- Connected to business risk.
- Updated when scope changes.
