# Test Scenarios And Test Cases

## Test Scenario

A test scenario is a high-level condition to test.

Example:

```txt
Verify that a user can log in with valid credentials.
```

## Test Case

A test case is a detailed set of steps, input, expected result, and status.

Common fields:

- Test case ID
- Title
- Preconditions
- Test steps
- Test data
- Expected result
- Actual result
- Status
- Priority

Good test cases are:

- Clear
- Reusable
- Traceable
- Independent where possible
- Written from requirement and user risk
