# Test Data And Checklists

Test data is the input used to execute test cases.

Useful test data categories:

- Valid data
- Invalid data
- Boundary data
- Empty data
- Duplicate data
- Special characters
- Large values
- Expired data
- Role-based data

Checklist testing is useful for repeated flows.

Example checklist for a form:

- Mandatory fields validated
- Optional fields accepted
- Field length rules checked
- Error messages clear
- Save button behavior correct
- Cancel behavior correct
- Data persists after refresh
- UI works on supported browsers
