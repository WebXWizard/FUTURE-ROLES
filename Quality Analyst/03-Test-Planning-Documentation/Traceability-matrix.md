# Traceability Matrix

RTM means Requirement Traceability Matrix.

Purpose:

- Map requirements to test cases.
- Show test coverage.
- Identify missing tests.
- Support audit and release confidence.

Simple RTM columns:

- Requirement ID
- Requirement description
- Test scenario ID
- Test case ID
- Execution status
- Defect ID
- Remarks

Example:

```txt
REQ-LOGIN-01 -> TC-LOGIN-001, TC-LOGIN-002, TC-LOGIN-003
```

Interview line:

```txt
RTM helps prove that requirements are covered by tests and defects are traceable to impacted requirements.
```
