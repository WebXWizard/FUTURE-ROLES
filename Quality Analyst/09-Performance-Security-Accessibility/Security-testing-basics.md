# Security Testing Basics

Security testing checks whether the application protects data and access.

Basic checks:

- Login and logout
- Password policy
- Session expiry
- Role-based access
- Direct URL access
- Input validation
- Error message leakage
- File upload restrictions
- Sensitive data exposure

Common web risks:

- SQL injection
- XSS
- CSRF
- Broken authentication
- Broken access control

QA habit:

- Try to access data or actions not allowed for the current role.
