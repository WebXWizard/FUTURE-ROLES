# Compatibility And Reliability

Compatibility testing checks whether software works across supported environments.

Examples:

- Browser versions
- Operating systems
- Devices
- Screen sizes
- Network conditions
- Database versions

Reliability testing checks whether software behaves consistently over time.

Examples:

- Retry behavior
- Failover behavior
- Session stability
- Data consistency
- Error recovery
- Long-running workflow stability

QA priority:

- Test the most common and most risky environments first.
