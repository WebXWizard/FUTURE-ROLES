# Accessibility Testing

Accessibility testing checks whether people with different abilities can use the application.

Basic checks:

- Keyboard navigation
- Visible focus
- Proper labels
- Meaningful alt text
- Color contrast
- Heading order
- Error message clarity
- Screen reader friendly structure

Tools:

- Browser keyboard
- Lighthouse
- axe DevTools
- Screen reader basics

Interview line:

```txt
Accessibility is part of product quality, not an optional final check.
```
