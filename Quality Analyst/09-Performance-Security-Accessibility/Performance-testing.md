# Performance Testing

Performance testing checks how the system behaves under load.

Types:

- Load testing: expected user load
- Stress testing: beyond expected limit
- Spike testing: sudden traffic increase
- Endurance testing: long duration load
- Volume testing: large data volume

Metrics:

- Response time
- Throughput
- Error rate
- CPU usage
- Memory usage
- Network usage

QA responsibility:

- Understand performance requirements.
- Prepare realistic test data.
- Identify critical user flows.
- Report bottlenecks with evidence.
