# Quality Analyst Revision

This folder is a structured Quality Analyst learning path for learning manual QA, API testing, database validation, automation basics, defect management, and interview preparation.

Use it like this:

1. Start with `00-Quality-Analyst-Plan`.
2. Read each folder's `Study.md`.
3. Revise topic-wise files.
4. Practice `Interview-questions.md`.
5. Build the projects in `12-QA-Projects`.
6. Use `14-Rapid-Revision` before interviews.

Daily routine:

```txt
45 min QA concepts
60 min test case or API practice
45 min project work
30 min interview questions
15 min bug report or test summary writing
```

QA answer formula:

```txt
Requirement -> Risk -> Test scenario -> Test data -> Expected result -> Defect evidence -> Business impact
```

Core goal:

```txt
Learn how to understand requirements, design effective tests, find defects, communicate clearly, validate data, use tools, and explain QA decisions.
```
