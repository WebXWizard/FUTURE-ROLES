# Backend Testing

Backend testing checks server-side behavior and data handling.

Areas:

- API response correctness
- Database updates
- Business rules
- Error handling
- Logs
- Job processing
- Notification triggers
- Data consistency between services

Examples:

- Payment success updates order status.
- Failed payment does not create shipment.
- Password reset token expires correctly.
- Admin role can access admin data, normal user cannot.

Evidence:

- API request and response
- Database query result
- Log entry
- Test data details
