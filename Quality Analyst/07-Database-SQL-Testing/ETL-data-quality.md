# ETL And Data Quality

ETL means Extract, Transform, Load.

Data quality checks:

- Completeness
- Accuracy
- Consistency
- Uniqueness
- Timeliness
- Validity

Common ETL test checks:

- Source count matches target count.
- Required fields loaded.
- Transformations applied correctly.
- Duplicate records handled.
- Invalid data rejected or flagged.
- Historical data retained correctly.

Useful QA question:

```txt
What should happen to bad data during import?
```
