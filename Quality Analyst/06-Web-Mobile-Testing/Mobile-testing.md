# Mobile Testing

Mobile testing checks behavior on mobile devices and operating systems.

Areas to test:

- Install and uninstall
- Launch behavior
- Permissions
- Login and logout
- Network change
- Airplane mode
- Incoming call or notification
- Orientation change
- Battery and memory behavior
- Device compatibility
- App update
- Crash recovery

Mobile-specific evidence:

- Device model
- OS version
- App version
- Network type
- Screen recording
- Logs if available
