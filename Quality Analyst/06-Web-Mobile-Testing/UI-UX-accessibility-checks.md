# UI, UX, And Accessibility Checks

UI checks:

- Text alignment
- Color consistency
- Button states
- Field spacing
- Icons
- Error message placement
- Loading state
- Empty state

UX checks:

- User can complete task easily.
- Labels are understandable.
- Error messages guide the user.
- Important actions are visible.
- Confirmation appears after action.

Accessibility checks:

- Keyboard navigation works.
- Focus is visible.
- Images have alt text when needed.
- Color contrast is readable.
- Forms have labels.
- Error messages are announced or easy to find.
