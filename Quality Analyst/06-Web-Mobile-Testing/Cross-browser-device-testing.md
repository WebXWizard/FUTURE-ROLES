# Cross Browser And Device Testing

Cross-browser testing validates behavior across supported browsers.

Check:

- Chrome
- Firefox
- Edge
- Safari if in scope
- Mobile browsers

Device testing checks:

- Desktop
- Tablet
- Mobile
- Different screen sizes
- Touch behavior
- Keyboard behavior

Prioritize by:

- User analytics
- Business critical flows
- Known risk areas
- Recently changed features

Mini task:

- Test one page at 1366px, 1024px, 768px, 390px, and 360px widths.
