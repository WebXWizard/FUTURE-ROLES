# Web Testing

Common web testing areas:

- Page load
- Navigation
- Links
- Forms
- Search
- Filters
- Sorting
- Pagination
- File upload
- Error messages
- Session handling
- Cookies and local storage
- Browser compatibility
- Responsive layout

Useful tools:

- Browser DevTools
- Network tab
- Console tab
- Lighthouse
- BrowserStack or similar cross-browser tools

Web defect evidence:

- Browser name and version
- Screen size
- Steps to reproduce
- Screenshot or video
- Console errors
- Network request details
