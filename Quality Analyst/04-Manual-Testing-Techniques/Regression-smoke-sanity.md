# Regression, Smoke, And Sanity

## Smoke Testing

Smoke testing checks whether the build is stable enough for deeper testing.

Example:

- App opens.
- Login works.
- Main navigation works.
- Critical API responds.

## Sanity Testing

Sanity testing checks a specific fix or small changed area.

## Regression Testing

Regression testing checks whether new changes broke existing functionality.

## Retesting

Retesting checks whether a specific defect fix works.

Interview tip:

- Retesting checks the fixed bug.
- Regression checks related existing features.
