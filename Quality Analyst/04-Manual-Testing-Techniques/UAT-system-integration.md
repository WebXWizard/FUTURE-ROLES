# UAT, System, And Integration Testing

## Integration Testing

Checks whether modules work together.

Example:

```txt
Order service sends payment status to notification service.
```

## System Testing

Checks the complete application end to end.

Example:

```txt
User signs up, logs in, buys a product, and receives confirmation.
```

## UAT

User Acceptance Testing validates business expectations with user or stakeholder involvement.

QA support in UAT:

- Prepare test data.
- Share test cases.
- Help reproduce defects.
- Track issues.
- Confirm acceptance criteria.
