# Bug Reporting

A good bug report helps developers reproduce and fix the issue quickly.

Common fields:

- Title
- Environment
- Build version
- Preconditions
- Steps to reproduce
- Expected result
- Actual result
- Severity
- Priority
- Attachments
- Logs or API details
- Defect owner

Good bug title:

```txt
Checkout: Payment succeeds but order status remains Pending
```

Poor bug title:

```txt
Checkout not working
```
