# Jira Workflow

Jira is commonly used to track stories, tasks, and defects.

QA uses Jira to:

- Review user stories.
- Add test notes.
- Link bugs to stories.
- Track defect status.
- Comment retest results.
- Share attachments.
- Report test progress.

Useful Jira fields:

- Issue type
- Summary
- Description
- Priority
- Assignee
- Sprint
- Component
- Labels
- Attachments
- Linked issues

Good habit:

- Keep bug comments factual and evidence-based.
