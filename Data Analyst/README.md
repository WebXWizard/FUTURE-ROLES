# Data Analyst Revision

This folder is a structured Data Analyst learning path for Excel, SQL, Python, statistics, visualization, BI tools, business analytics, projects, and interview preparation.

Use it like this:

1. Start with `00-Data-Analyst-Plan`.
2. Read each folder's `Study.md`.
3. Practice topic-wise tasks.
4. Revise `Interview-questions.md`.
5. Build projects in `10-Analytics-Projects`.
6. Use `14-Rapid-Revision` before interviews.

Daily routine:

```txt
45 min concepts
60 min Excel, SQL, or Python practice
45 min dashboard or project work
30 min interview questions
15 min business explanation practice
```

Data Analyst answer formula:

```txt
Business question -> Data source -> Cleaning -> Analysis -> Insight -> Recommendation -> Impact
```
