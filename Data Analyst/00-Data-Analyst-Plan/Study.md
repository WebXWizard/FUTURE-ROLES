# Data Analyst Study Plan

Data Analysts turn raw data into business insights.

Focus on:

- Business questions and KPIs
- Excel and spreadsheets
- SQL querying
- Python data analysis
- Statistics and probability
- Data cleaning
- Dashboards and visualization
- BI tools
- Storytelling and stakeholder communication

Suggested order:

1. Data analytics fundamentals
2. Excel and Google Sheets
3. SQL
4. Python for data analysis
5. Statistics
6. Data cleaning
7. Visualization
8. BI tools
9. Projects and mock interviews
