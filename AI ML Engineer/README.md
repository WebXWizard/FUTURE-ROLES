# AI ML Engineer Revision

This folder is a structured AI ML Engineer learning path for machine learning, deep learning, NLP, LLMs, computer vision, model evaluation, deployment, responsible AI, system design, projects, and interview preparation.

Use it like this:

1. Start with `00-AI-ML-Engineer-Plan`.
2. Read each folder's `Study.md`.
3. Practice algorithms and model building.
4. Revise `Interview-questions.md`.
5. Build projects in `10-AI-ML-Projects`.
6. Use `14-Rapid-Revision` before interviews.

Daily routine:

```txt
45 min theory
60 min coding or model practice
45 min project work
30 min interview questions
15 min model explanation
```

AI ML answer formula:

```txt
Problem -> Data -> Features -> Model -> Training -> Evaluation -> Deployment -> Risk
```
